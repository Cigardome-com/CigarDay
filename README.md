# CigarDay — тестовый бот подбора сигар

Прототип «посмотреть и пощупать»: Telegram-бот показывает покупателю его
любимые сигары, которые есть в наличии в CigarDay, и три похожие. Покупки
можно оценить звёздами (1–5), и подборка сразу меняется.

На этом шаге **нет** рассылки, заказов и СБИС. 15-ФЗ: никаких скидок,
акций, призывов купить и кнопки «заказать» — цена и наличие только как
информация. Тексты перед живым запуском показать юристу CigarDay.

## Как устроено

| Файл | Что делает |
|---|---|
| `cigarday/reco.py` | подбор: похожесть по крепости, формату, размеру, странам листов и нотам; цена ±30% от обычной для клиента; оценки |
| `cigarday/reco_match.py` | история покупок текстом → сигары каталога (алиасы CigarIndex, `scrape.match_listing`) |
| `cigarday/reco_text.py` | карточки сигар и демо-истории |
| `cigarday/bot.py` | бот: /start, /demo1, /demo2, /load, /rate, /pick, /stop |
| `cigarday/cigardome_profile.py` | разовый сбор профилей с cigardome.com → `data/cigar_profile.json` |
| `cigarday/reco_demo.py` | подборка текстом в терминале, без бота |
| `tests/test_reco.py` | тесты подбора, без сети |

Цены, наличие и алиасы бот берёт у CigarIndex (`/opt/cigarindex/data`,
обновляется ночью и в 12:00/18:00), сам туда ничего не пишет. Путь меняется
переменной `CIGARINDEX_ROOT`.

**Данные пользователей в репозиторий не попадают** (он публичный): истории,
оценки и согласие лежат на сервере в `/var/lib/cigarday-bot/users/<chat_id>.json`
(0600); `/stop` удаляет файл целиком.

## Запуск

```
python3.13 tests/test_reco.py
CIGARINDEX_ROOT=../cigar_scrapper python3.13 cigarday/reco_demo.py demo1 --rate "partagas-serie-d-no-4=5"
```

Сервер — см. комментарий в `deploy/cigarday-bot.service`. Telegram с сервера
доступен только по IPv6, поэтому запросы идут через `curl -6`.
